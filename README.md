ENTROPY

Instead of making unpredictability a role, make it an actual game system.

There is an Entropy Meter:

STABLE ███░░░░░░░ CHAOTIC

Normal gameplay increases entropy:

kills +15%
sabotages +8%
meetings +10%
venting +3%
task completion -2%

As entropy rises, increasingly crazy anomalies become possible.

0–25%

lights flicker
doors malfunction
cooldown changes

25–50%

player swaps
vent rerouting
fake footsteps / sounds
anonymous players

50–75%

fake bodies
temporary role abilities
random sabotages
inverted controls

75–100%

massive events
everyone teleports
roles temporarily swap
dead player revived
two players exchange identities
map rooms get scrambled

And at 100%:

REALITY COLLAPSE

Some huge game-changing event happens and entropy resets.

That gives you unpredictability without making the game feel like pure RNG, because players can see chaos building and potentially influence it.
